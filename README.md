# মানুষের জন্য

### A Community Assistance Platform Connecting People Who Need Help with People Who Want to Help

মানুষের জন্য is a community-focused full-stack web platform designed to connect people who need assistance with volunteers and individuals who are willing to help.

The platform uses location-based services, user roles, real-time activities, and AI-powered functionality to make community assistance more accessible and organized.

## 🌐 Live Demo

https://manusherjonnoo.vercel.app/

## ✨ Features

- User registration and authentication
- User, Volunteer, and Admin roles
- Create and manage help requests
- Location-based assistance discovery
- Interactive map
- Volunteer assistance system
- Image upload for help requests
- Notifications and activity updates
- Admin dashboard
- User and volunteer management
- AI-powered functionality

## 👥 User Roles

### User
Users can:
- Create assistance requests
- Discover nearby assistance opportunities
- Offer help
- Upload relevant images
- Track their activities

### Volunteer
Volunteers can:
- Browse help requests
- Respond to requests
- Provide assistance
- Track volunteering activities

### Admin
The administrator can:
- Manage users
- Manage volunteers
- Monitor activities
- Manage assistance requests
- Maintain the overall platform

## 🔄 How It Works

1. Create an account or log in
2. Explore available assistance opportunities
3. Create a help request or offer assistance
4. Volunteers can respond to relevant requests
5. Users and volunteers can communicate through the platform
6. Assistance activities are tracked through the system

## 🏗️ Project Architecture

The application follows a full-stack architecture:

Frontend → Backend/API → Database & External Services

The frontend provides the user interface, while the backend handles application logic, API operations, authentication-related services, and database communication.
